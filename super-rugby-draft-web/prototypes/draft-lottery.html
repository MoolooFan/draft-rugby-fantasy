    Fairness check

    Runs 2,000 hidden races with random seeds and counts how often each team takes pick 1. Each should land near the marker; a point or two either way is sampling noise.

    In the app, the server would pick the seed at the lottery time and save the order; every phone then replays the same race from that seed, so nobody sees a different result.
